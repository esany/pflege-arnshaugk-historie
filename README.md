# pflege-arnshaugk-historie

Arbeitsrepository für historische Forschung zur Pflege Arnshaugk und für die Entwicklung eines **persönlichen Archivars / transdisziplinären Forschungsassistenten**.

## Aktueller Konzeptstand

Der aktuelle Ansatz ist bewusst **research-first**: Noch keine vorschnelle Zielarchitektur festlegen, sondern vom realen Forschungsalltag ausgehen und bestehende Lösungen systematisch prüfen.

```text
Zielbild / Forschungsalltag
        ↓
Problem- und Workflow-Map
        ↓
Leane State-of-the-Art-Analyse
        ↓
Capability Map
        ↓
Rollen- / Kompetenzmodell
        ↓
Transdisziplinäres Gesamtkonzept
        ↓
Architekturentscheidungen
        ↓
Requirements / MVP / Implementation
```
